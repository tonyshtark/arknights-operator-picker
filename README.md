# Arknights Operator Picker · 明日方舟干员随机抽选

一个纯前端的明日方舟干员随机抽选小工具，打开 `index.html` 即可使用，无需安装或联网。

## 功能

- 收录 432 名可获得干员（一至六星），默认只抽六星
- 按 **星级**、**职业** 筛选卡池（Ctrl / Shift + 点击只选该项）
- 自定义抽取数量，可选是否允许重复
- **重抽**：整组重新抽取；点卡片左上角的 ↻ 只重抽这一位
- **再抽 N 个**：在当前结果后面追加 N 位新干员，已抽出的不变；也可以从零开始一个个加，还没出现的必出干员会优先加入
- **锁定**：点击卡片锁定，重抽时保留该干员，再点一次解锁；提示栏有「全部锁定」「全部解锁」
- **删除**：点卡片右上角的 × 删除这位干员；「删除全部」一次清空所有抽出的干员
- **撤销 / 重做**：重抽、单张重抽、再抽、删除、锁定等操作都可以撤销（最多 30 步），撤销过头可以重做；快捷键 Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做（Mac 用 ⌘）
- **指定干员**：搜索干员名（支持拼音、首字母），设为「必出」（每次必定抽到）或「排除」（永远不会抽到），设置保存在本浏览器；也可点「选择必出 / 选择排除」打开头像面板，按星级、职业筛选后点选
- **添加干员**：搜索结果里的「添加」按钮，或「＋ 添加干员」打开头像面板点选，把指定干员直接加入当前结果（不受筛选限制，可锁定、删除、撤销）；再点一次移出
- **小窗展示**：右上角按钮打开一个小窗口，以圆形或方形头像同步显示当前抽出的干员，并按窗口形状自动排布：能一次放下就排成一行或多行、头像尽量大，放不下时排成一行循环滚动（至少显示 6 位，窗口越长显示越多）；小窗本身不显示任何控件，方向、形状、滚动速度、背景（纯白 / 绿幕 / 纯黑 / 自定义颜色）都在主页面的「小窗」一行调整，适合用 OBS 放进直播画面（见下方「直播 / OBS 使用」）
- **OBS 浏览器源（Beta）**：结果直接显示在 OBS 的浏览器来源里，背景透明，本页面最小化或被遮挡也照常同步
- 每张卡片附精英化立绘，并可跳转到 PRTS 查看详情

## 使用

- 在线：<https://arknights-operator-picker.pages.dev>（备用：<https://tonyshtark.github.io/arknights-operator-picker/>）
- 本地：下载后双击 `index.html`（`img` 文件夹需与其放在同一目录）

## 直播 / OBS 使用

1. 抽取后点右上角「▶ 小窗展示」打开小窗，之后抽取、重抽、删除都会同步到小窗：单张重抽只替换那一位，删除不打断滚动，整组重抽会淡出淡入。
2. 在主页面「小窗」一行设置方向、形状、滚动速度和背景；每次打开小窗默认横向，切换横向 / 竖向时小窗会自动变成横长或竖长。
3. OBS 添加「窗口采集」来源，窗口选「小窗展示 · 干员抽选」；小窗顶部的地址栏可在 OBS 里按住 Alt 拖动上边框裁掉，或用「裁剪/填充」滤镜裁掉。
4. 去掉背景（绿幕抠图）：小窗背景选「绿幕」，在 OBS 里右键来源 →「滤镜」→ 添加 **颜色键**（不建议用色度键，它会把同色系一起抠掉）：
   - 关键色类型：绿色
   - 相似度：200 左右（150～250）
   - 平滑：140 左右（100～200）
   - 头像边缘有绿边 → 调高平滑；绿色较多的干员（如嘉维尔、维荻）被抠出洞 → 调低相似度
   - 使用自定义背景色时，关键色类型选「自定义颜色」并填同一个色号

### OBS 浏览器源（Beta 测试功能）

不用弹出小窗和绿幕：画面直接在 OBS 的浏览器来源里显示，背景透明，网页最小化或被其他窗口挡住也照常同步、照常滚动。目前还在测试，正式开播前请先完整试一遍，出问题可以随时改回上面的小窗方式。

1. OBS 菜单「工具 → WebSocket 服务器设置」，勾选「开启 WebSocket 服务器」，点「显示连接信息」查看端口和密码。
2. 网页右上角点「OBS 浏览器源」，复制面板里的浏览器源网址（以 `#obs` 结尾）。
3. OBS 添加「浏览器」来源，不勾选「本地文件」，网址填刚才复制的那一行；宽 1120、高 210（竖向可用 210 × 1120）。
4. 回到网页填好 WebSocket 地址（默认 `ws://127.0.0.1:4455`）和密码，点「连接 OBS」，状态变绿即可。

使用规则与注意事项：

- 需要 OBS 28 或更新版本；OBS 和网页要在同一台电脑上。
- 网页要一直开着（可以最小化，不能关掉标签页）；同一时间只用一个页面连接 OBS。
- 抽取、重抽、再抽、添加、删除、撤销 / 重做都会实时同步；方向、形状、滚动速度沿用「小窗」一行的设置，背景始终透明。
- 连接成功后会记住，下次打开自动重连；断线会自动重试。OBS 里的浏览器源刷新后先显示上一次的结果，最多 5 秒内对上最新结果。
- WebSocket 密码只保存在本浏览器，开播或共享屏幕时注意别露出设置面板。
- 浏览器询问是否允许访问本地网络 / 设备时请选「允许」。
